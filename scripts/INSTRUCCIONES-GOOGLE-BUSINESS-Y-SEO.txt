--- PARTE 2: Google Search Console ---

1. https://search.google.com/search-console
2. Agregar propiedad → Prefijo de URL:
   https://electricidadituartesur.com.ar
3. Verificación recomendada: registro DNS TXT en DonWeb
   (Search Console te da un registro tipo google-site-verification=...)
   DonWeb → Zona DNS → Agregar TXT con el valor que indica Google
4. Cuando verifique → Sitemaps → agregar:
   https://electricidadituartesur.com.ar/sitemap.xml
5. Pedir indexación de la home (Inspección de URL → Solicitar indexación)

--- PARTE 3: En el servidor (después de generar sitemap en PC) ---

En PC:
  cd ProyectoTesis
  node scripts/generar-sitemap.js
  git add robots.txt sitemap.xml scripts/
  git commit -m "SEO: robots.txt y sitemap"
  git push origin master

En droplet:
  cd /var/www/ProyectoTesis && git pull

Probar:
  https://electricidadituartesur.com.ar/robots.txt
  https://electricidadituartesur.com.ar/sitemap.xml
